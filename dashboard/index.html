Token Launch Radar

Every protocol that still records no token, ranked by what its token would be worth if its record stayed as it is — and how to farm each one before it launches.

The model, stated plainly: implied value = TVL × sector multiple × momentum × maturity × breadth. The sector multiple is the FDV/TVL tokens in that sector launch at; momentum damps the snapshot's own 7-day TVL change; maturity rewards a long tokenless record; breadth adds a little per extra chain. No name is hardcoded: change the snapshot and the board re-ranks itself.
